# 7 Days of Python Projects Challenge

Welcome to my **7 Days of Python Projects Challenge** 

As someone who has already explored AI/ML and worked on advanced tech projects using Python, I wanted to take up this challenge to strengthen my fundamentals through consistent hands-on building.

This challenge is all about building one Python project every day — not just to practice coding, but to improve creativity, logical thinking, debugging skills, and confidence while building independently.

Sometimes revisiting the basics in a practical way is one of the best ways to grow as a developer 🚀

---

## Projects Included

### Day 1 — QR Code Generator

Generate custom QR codes for links and text.

### Day 2 — Email Validator

Validate email addresses using Python.

### Day 3 — Typing Speed Test

Test typing speed and accuracy.

### Day 4 — Weather App

Fetch and display real-time weather details.

### Day 5 — Screenshot Tool

Capture screenshots directly using Python.

### Day 6 — Hangman Game

Build the classic word guessing game.

### Day 7 — Snake Game

Create the nostalgic snake game using Python.
