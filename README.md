# 7 Days of Python Projects Challenge

## Introduction

This repository contains my **7 Days of Python Projects Challenge**, where I built one Python project every day to strengthen my programming fundamentals through hands-on development.

Although I have previously worked on AI/ML and other advanced technology projects, this challenge was an opportunity to revisit core Python concepts, improve problem-solving skills, and build projects independently from scratch.

The goal was to focus on consistency, creativity, debugging, and practical application of Python while developing a diverse set of mini-projects.

---

## Projects

### Day 1 — QR Code Generator

Generate QR codes from text or URLs.

### Day 2 — Email Validator

Validate email addresses using pattern matching and input validation.

### Day 3 — Typing Speed Test

Measure typing speed and accuracy through a simple terminal-based application.

### Day 4 — Weather App

Fetch and display real-time weather information using an external API.

### Day 5 — Multiple Mail Sender

Send emails to multiple recipients efficiently using Python automation.

### Day 6 — Screenshot Tool

Capture and save screenshots directly using Python.

### Day 7 — Hangman Game

A classic word-guessing game built using Python and GUI-based interaction.

---

## Key Insights

This challenge reinforced an important lesson: building simple projects consistently can be just as valuable as working on complex ones.

While I had previously explored AI/ML and other advanced technologies, these projects helped me revisit Python fundamentals and strengthen the skills that form the foundation of every developer's journey.

Some key takeaways from this challenge:

* Strong fundamentals make learning advanced technologies easier.
* Consistency often produces better results than occasional bursts of effort.
* Debugging is one of the fastest ways to improve as a programmer.
* Small projects can teach practical problem-solving and software design.
* Building independently improves confidence and reduces reliance on tutorials.
* Every project, regardless of size, contributes to a stronger development mindset.

This challenge was not just about completing seven projects—it was about developing discipline, improving logical thinking, and becoming a more confident Python developer through daily hands-on practice.
